# Project CardSurvival

## 실행

Unity 6000.4.0f1에서 `Assets/Scenes/Prototype.unity`를 열고 Play를 누릅니다. macOS 개발 빌드는 `Builds/Paperkeep.app`에 있습니다. Windows 실행 파일은 아직 만들지 않았습니다.

휠로 확대·축소하고 WASD 또는 좌클릭 드래그로 이동합니다. 성을 확대하면 시설이 나타납니다. 시설 더블클릭은 테크트리, 길드 클릭은 영웅 의뢰창을 엽니다. 손패의 영웅은 클릭해 투입하고 마법은 선택 후 전장을 클릭합니다. Space 또는 Esc로 일시정지합니다.

[실행·조작·구조 안내](Assets/Documentation/README.md)

## 게임 기획 및 구현 기준

[게임 개요 및 구현 명세](Assets/Documentation/Unity_AI_Implementation_Spec.md)를 참고합니다.

판타지 2D 탑다운 카드 디펜스 게임으로, 고블린·오크와 사이클롭스 보스에 맞서 중앙 성을 지키며 30분 생존하는 것이 목표입니다.

- 군은 예약 없이 근접병을 주기적으로 생산하며, 원거리 테크 해금 후에는 궁수도 독립 주기로 자동생산합니다.
- 영웅은 S·A·B·C·D 등급별로 의뢰하고, 의뢰 시간이 지나면 해당 등급 영웅 카드를 받습니다.
- 마법은 생산 예약과 골드 결제 없이 일정 시간마다 카드 1장을 자동 지급합니다.
- 완성 카드는 공용 덱에 보관하고 빈 손패를 자동 보충합니다. 카드를 버릴 수 없습니다.
- 사이클롭스 보스를 처치하면 무작위 증강 3개 중 하나를 선택합니다. 시간 경과만으로는 증강을 지급하지 않습니다.
- 플레이어는 영웅 의뢰·투입, 마법 사용, 시설 테크트리와 증강 선택에 개입합니다.

종이 카드 UI와 전장 유닛, 독자 제작한 일러스트 13종을 포함합니다. 마법은 기본 10초마다 공격·회복 카드를 교대로 지급합니다. 시설 테크트리 48개 노드와 보스 처치 증강 12종을 구현했습니다. 수치와 간격은 `Assets/Resources/CardSurvival/Content.asset`에서 조정할 수 있습니다.

## 검증 상태

- EditMode 규칙 테스트 34개, PlayMode 씬 통합 테스트 1개 통과.
- macOS 개발 빌드 성공, 오류 0개.
- 6개 빌드 자동 시뮬레이션에서 영웅 중심 빌드의 30분 생존 확인. 다른 빌드는 패배하여 밸런스 추가 조정이 필요합니다. 이는 실제 속도 수동 플레이 검증이 아닙니다.
- 별도 앱 실행 권한 요청이 거절되어 Standalone 30분 실행과 성능 검증은 수행하지 않았습니다. FPS를 보장하지 않습니다.

검증 결과는 `Artifacts/`, 원본 아트와 생성 프롬프트는 [아트 기록](Assets/Documentation/ArtPrompts.md)에 있습니다. 상세 명세의 모든 목표가 검증 완료되었다는 뜻은 아닙니다.
